EduPulse - Web Development Project
Team Leader: Delaksan
Team Members: Kthihara, Sunera, Nusry

Overview
This project, EduPulse, was created for the Semester 2 First Year Web Development module coursework. It is inspired by the UN's 16 Goals, with a focus on the topic of Education.

Project Description
EduPulse is a website comprising several pages, each serving a specific purpose:

Splash Page: An introductory page to welcome visitors.

Volunteer Page: A page for users to find information on how to volunteer.

Feedback Form: A form for users to submit their feedback.

Home Page: The main page of the website.

Table Page: A page displaying data in a tabular format.

Team Page: Information about the development team.

Profile Page: User profile page.

Site Map: A page showing the structure of the website.

Validation Page: A page for input validation.

Content Page: A page displaying specific content.

Page Editor: A page with content editing capabilities.

Accomplishments
As a team, we successfully developed and implemented all the mentioned pages, demonstrating our ability to work collaboratively and achieve the objectives of the coursework.
