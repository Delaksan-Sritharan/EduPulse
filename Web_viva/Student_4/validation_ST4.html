Recommended Fixes

1. Remove trailing slashes from void elements

In HTML5, void elements (such as meta, link, img, input, br, hr) should not have trailing slashes.

Incorrect:

<meta charset="UTF-8" />
<link rel="stylesheet" href="styles.css" />
<img src="images/logo.png" alt="Learn UN Logo" />

Correct:

<meta charset="UTF-8">
<link rel="stylesheet" href="styles.css">
<img src="images/logo.png" alt="Learn UN Logo">

2. Remove stray end tag

Remove the stray </a> tag at line 46, column 25 or ensure it has a matching opening tag.

Incorrect:

... some content ...
</a>
... more content ...

Correct (remove if it's a stray tag):

... some content ...
... more content ...

3. Add missing alt attributes to images

Ensure all images have descriptive alt text for accessibility.

Incorrect:

<img src="images/header.jpg">

Correct:

<img src="images/header.jpg" alt="Educational resources for sustainable development">

HTML Best Practices

HTML5 Doctype

Always include the HTML5 doctype at the beginning of your HTML documents: 

<!DOCTYPE html>

Character Encoding

Always specify the character encoding in the head section:

<meta charset="UTF-8">

Viewport Meta Tag

Include the viewport meta tag for responsive design:

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Semantic HTML

Use semantic HTML elements to improve accessibility and SEO:

<header>, <nav>, <main>, <section>, <article>, <aside>, <footer>

Void Elements in HTML5

In HTML5, void elements should not have trailing slashes:

<br>, <hr>, <img>, <input>, <link>, <meta>

Accessibility

Ensure your site is accessible by:

  • Using appropriate heading hierarchy (h1-h6)
  • Adding alt text to images
  • Using ARIA attributes when necessary
  • Ensuring sufficient color contrast
  • Making your site keyboard navigable
