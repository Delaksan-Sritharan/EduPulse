1. Technical Description - Splash Screen

The Splash Screen provides a smooth transition for users before navigating to the homepage. It displays an introductory message with a loading animation and automatically redirects to the home page after a delay.

HTML Implementation

  • The splash screen is contained within a <div> element with the id="start". The content includes a heading (<h2>) displaying a message.
  • The second section (<div id="end">) appears after the splash screen fades out, showing the website's name and group members.
  • A <script> tag is used to handle the timed transitions between the splash screen, content, and the homepage.

CSS Implementation

  • The entire screen height (height: 100vh) is utilized to center content vertically.
  • Text alignment and fonts: text-align: center; font-family: "Times New Roman", Times, serif; ensure readability and consistency.
  • Loading Animation: Implemented with the .loader class using @keyframes shadowRolling for a dynamic effect.
  • Fade-in effect: Applied via the @keyframes fadeIn animation to transition text smoothly.
  • Hidden and visible states: display: none; and display: block; control visibility at different stages.

Organization

  • Section 1: start div - Displays initial message and loader animation.
  • Section 2: end div - Shows the website title and team members before redirecting.
  • JavaScript: Handles timing and redirections.

2. Technical Description - Volunteer Page

HTML Techniques Used

  • Used <div> elements to create a structured layout for different sections.
  • Implemented <nav> for site navigation, ensuring accessibility and usability.
  • Used <ul> and <li> for the navigation bar to maintain semantic structure.
  • Included <button> elements for user interactions like applying for volunteer opportunities.
  • Used <h2> and <p> for structured content display, improving readability.

CSS Techniques Used

  • Applied flexbox for responsive design and alignment.
  • Used background-image with background-size: cover to create visually appealing hero sections.
  • Implemented @media queries to ensure the page is mobile-friendly.
  • Styled buttons with hover effects using transition and box-shadow to enhance user interaction.

Organization

  • The page follows a clear hierarchical structure with headers, sections, and a well-defined navigation menu.
  • The content is divided into logical sections, making it easy to read and navigate.
